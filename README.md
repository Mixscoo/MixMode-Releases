# MixMode downloads

Official binary downloads and release metadata for MixMode.

MixMode is a free, ad-free Windows app for supported offline games. The application source is maintained in a separate private repository.

## Download

Open [Releases](https://github.com/Mixscoo/MixMode-Releases/releases), choose the Windows x64 ZIP, extract the complete folder, then run `MixMode.exe`. The .NET runtime is included.

The first release is an unsigned beta. Windows may ask you to review an unfamiliar publisher. No game files are bundled. A legitimate installed game is required; Steam and game ownership checks are not bypassed.

Cup & Counter support requires exact supported binary/metadata hashes. Gameplay verification is pending user testing. Back up your save before testing persistent changes.

## Updates

`releases.json` is the public feed consumed by the website API and desktop app. App releases and per-game trainer packages have independent versions and SHA-256 checksums. Game packages can be updated independently, with the trainer stopped.

No advertising, payments or account registration are required.
